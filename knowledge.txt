DROSOPHILA MALE CNS CONNECTOME DATA KNOWLEDGE BASE
================================================================================

1. OVERVIEW & DATASET SOURCE
--------------------------------------------------------------------------------
This dataset represents the full adult male Drosophila melanogaster central
nervous system (CNS) connectome (FlyWire / Janelia Male CNS v1.0, minconf 0.5).
It encompasses both the brain (central brain and optic lobes) and the ventral
nerve cord (VNC), providing a complete sensory-to-motor connectomic graph.

Files Present:
- body-annotations-male-cns-v1.0-minconf-0.5.feather (~14.5 MB)
- body-neurotransmitters-male-cns-v1.0.feather        (~43.3 MB)
- connectome-weights-male-cns-v1.0-minconf-0.5.feather (~1.05 GB)

  * superclass & class: Anatomical / functional categorization:

3. NEUROTRANSMITTERS (body-neurotransmitters-male-cns-v1.0.feather)
--------------------------------------------------------------------------------
- Schema: body, cell_type, total_nt_predictions, predicted_nt_confidence,
          predicted_nt, ground_truth, celltype_total_nt_predictions,
          celltype_predicted_nt, celltype_predicted_nt_confidence, consensus_nt.

- Consensus Neurotransmitter Classifications & Synaptic Polarities:
  * Acetylcholine (104,193):
    - Primary EXCITATORY (+1.0) neurotransmitter in insect CNS.
  * Glutamate (29,443):
    - In Drosophila CNS, glutamate acts predominantly via GluCl (glutamate-gated
      chloride channels) and is INHIBITORY (-1.0).
  * GABA (22,196):
    - Standard INHIBITORY (-1.0) neurotransmitter via GABA_A / GABA_B receptors.
  * Histamine (8,024):
    - INHIBITORY (-1.0), characteristic of insect photoreceptors (HisCl1).
  * Dopamine (396):
    - NEUROMODULATORY (+0.3 to +1.0), involved in reinforcement & arousal.
  * Octopamine (101):
    - NEUROMODULATORY (+0.3 to +1.0), insect analogue of norepinephrine.
  * Serotonin (48):
    - NEUROMODULATORY (+0.3 to +1.0), mood, circadian, state regulation.


4. CONNECTOME GRAPH & SYNAPSES (connectome-weights-male-cns-v1.0-minconf-0.5.feather)
--------------------------------------------------------------------------------
- Schema: body_pre, body_post, weight
- Total Raw Edges: 151,856,684 (~151.8 million directed synaptic edges).
- Synapse Weight: Represents the count of reconstructed synaptic contact sites.
  * Mean: 2.05 synapses per edge, Max: 2,591 synapses.
- Filtering by Proofread/Annotated Neurons:
  * The raw connectome file includes ~88 million IDs, the vast majority being
    micro-fragments and unproofread segments.
  * Edges where both pre and post belong to the annotated bodies: 26,028,386 edges.
  * Weight Thresholds across annotated connections:
    - Weight >= 1:  26,028,386 edges
    - Weight >= 3:  10,653,945 edges
    - Weight >= 5:   6,300,108 edges
    - Weight >= 10:  2,769,379 edges


5. NEURAL NETWORK SIMULATION & PERFORMANCE SPECIFICATIONS
--------------------------------------------------------------------------------
- Model Architecture: Leaky Integrate-and-Fire (LIF) Spiking Neural Network.
  * V(t+1) = V(t) * exp(-dt / tau_m) + I_syn + I_ext + Noise
  * When V >= V_thr (1.0): Spike = 1, V resets to V_reset (0.0), refractory period.
  * Signed Synaptic Weights:
      W_signed = Sign(NT_pre) * Weight
      Normalized per postsynaptic target or scaled by synaptic gain.
- Compute Hardware:
  * Running on CPU (PyTorch CPU / SciPy sparse).
  * Benchmark: PyTorch sparse CSR SpMV takes ~1.0 ms for 100,000 edges and ~1.3 ms
    for 1,000,000 edges across 50,000 neurons.
  * Subnetworks:
    - Core Active Subnetwork: 15,000 - 30,000 high-confidence neurons with
      500,000 - 1,500,000 strong synapses runs at 30-60 Hz in real-time.
    - Full Point Cloud: 141,781 3D soma locations visualized in WebGL / Three.js
      with spike-glow instanced buffer updates over WebSocket.


6. ARCHITECTURE FOR REAL-TIME WEB VISUALIZATION
--------------------------------------------------------------------------------
- Backend:
  * FastAPI + WebSockets server in Python.
  * PyTorch Sparse CSR LIF simulation loop running in background thread or async loop.
  * Real-time sensory injection (Visual, Olfactory, Mechanosensory inputs) and
    parameter updates (Gain, Noise, Tau, Stimulation) received over WebSocket.
  * Broadcasts spike events, membrane potentials, and population rates at 30-60 FPS.
- Frontend:
  * Three.js 3D Brain Anatomy Canvas: 3D point cloud of true fly brain morphology,
    color-coded by region/superclasses or neurotransmitter type, pulsing with spikes.
  * Real-time Electrophysiology Spike Raster: Multi-channel scrolling spike display
    (Sensory -> Interneurons -> Motor neurons).
  * Population Firing Rate & Motor Output Telemetry Charts: Live signal visualization
    and fly steering/behavior gauges.
  * Interactive Stimulation Dashboard: Trigger sensory inputs, inject micro-currents,
    toggle pharmacology (GABA/ACh blockers), and inspect individual neurons.
